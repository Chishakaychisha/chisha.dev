## 📦 How to Host on GitHub Pages

1. **Create a new repository on GitHub:**
   - Go to [GitHub New Repository](https://github.com/new)
   - Name the repository `chishakaychisha.github.io` (for direct user site) or `portfolio`

2. **Add remote and push:**
   ```bash
   git add .
   git commit -m "feat: initial commit of interactive developer portfolio"
   git remote add origin https://github.com/Chishakaychisha/<repo-name>.git
   git branch -M main
   git push -u origin main
   ```

3. **Enable GitHub Pages (if repo name is not `chishakaychisha.github.io`):**
   - In GitHub, go to **Settings** > **Pages**
   - Under **Build and deployment > Source**, choose `Deploy from a branch`
   - Select `main` branch and `/ (root)` folder
   - Click **Save**
